# Афіша культурних подій міста (`city-events`)

Клієнт-серверний односторінковий вебзастосунок (SPA) на базі React 18 та Node.js / Express, ПВЗ, ФІОТ, ІП-56, Ярощук Іван
## Запуск проєкту

    npm install
    npm start

Після запуску клієнтська частина застосунку доступна за адресою `http://localhost:3000`, а REST API — за адресою `http://localhost:3000/api/events`.

### 1. Аудит `innerHTML`, відтворення та усунення XSS-вразливості
- Перевірено весь код проєкту (`public/js/app.js`, `public/index.html`, `server.js`) на наявність вставок через `innerHTML` або неекранованих даних, що надходять від користувача через форму додавання події або з серверного API `/api/events`.
- У домені «Афіша культурних подій міста» критичними полями є назва події (`title`) та локація (`location`). Під час перевірки рендеру цих полів напряму через `innerHTML` без попереднього екранування введення тестового XSS-вектора `<img src=x onerror="alert('XSS')">` у форму призводило до ін'єкції HTML-тегу `<img>` у DOM та виконання довільного JavaScript-коду (`alert('XSS')`) у браузері.
- **Спосіб виправлення**
  1. Повністю видалено використання `innerHTML` для виводу будь-яких динамічних даних користувача та API.
  2. Рендер карток у компоненті `EventCard`, сторінки деталей у `EventDetailsView` та маршруту помилки у `render404` переведено на безпечні текстові вузли (JSX-інтерполяція в React, яка працює аналогічно до `textContent` і сприймає будь-який рядок виключно як текст, а не HTML-розмітку).
  3. Реалізовано функцію екранування спеціальних HTML-символів `escapeHtml(str)` (перетворення `&`, `<`, `>`, `"`, `'` на відповідні HTML-сутності `&amp;`, `&lt;`, `&gt;`, `&quot;`, `&#39;`) для безпечної підстановки значень у рядкові атрибути (`data-escaped-title`).
  4. Додано очищення пробілів (`trim()`) та перевірку обов'язкових полів під час створення нової події у формі.
- **Результат перевірки після виправлення** повторне введення рядка `<img src=x onerror="alert('XSS')">` у поля «Назва події» та «Локація» більше не викликає виконання скрипту — вектор безпечно відображається на картці як звичайний текст, а у вкладці DevTools `Elements` тег `<img>` відсутній.

### 2. Аудит клієнтських сховищ (`localStorage` та `IndexedDB`)
- **Перевірені сховища**
  - `localStorage` - використовується для зберігання резервної копії обраних подій під ключем `events_backup` та службового прапорця міграції `migrated_to_idb`.
  - `IndexedDB` (база даних `EventsDB`, версія `1`, об'єктне сховище `savedEvents` із ключем `id`) - зберігає об'єкти обраних подій (`id`, `title`, `category`, `date`, `location`, `price`, `description`).
- Отже, у клієнтських сховищах не зберігаються паролі, токени автентифікації, секретні ключі чи персональні дані користувачів — зберігаються лише публічні дані афіші культурних подій. Згідно з характеристикою Варіанту 5 ризик витоку чутливих даних є низьким. Додатково впроваджено функцію валідації структури об'єктів `isValidEventObject()` при читанні та записі даних у `localStorage` і `IndexedDB` для захисту від пошкоджених записів.

### 3. Перевірка відсутності захардкоджених секретів
- **Результат перевірки** 
- у клієнтському (`public/js/app.js`, `public/index.html`) та серверному (`server.js`) коді відсутні захардкоджені паролі, приватні токени або платні API-ключі. Клієнт звертається до локального відносного маршруту `/api/events`. У `server.js` вимкнено заголовок `X-Powered-By` (`app.disable('x-powered-by')`) для зменшення розкриття технічної інформації про сервер.

### 4. Роль HTTPS та вибір способу розгортання
- Локальна розробка ведеться за адресою `http://localhost:3000`, яку браузери розглядають як безпечний контекст. Однак у мережі звичайний HTTP вразливий до перехоплення й підміни трафіку (атаки типу Man-in-the-Middle) та обмежує роботу сучасних браузерних API.
- **Обраний спосіб публікації** 
-Для фінального розгортання проєкту з **HTTPS за замовчуванням** обрано платформи **Render** або **Vercel** (для повноцінного запуску клієнт-серверного застосунку разом із Node.js/Express сервером та автоматичним TLS-сертифікатом) або **GitHub Pages** (для статичної клієнтської версії).
