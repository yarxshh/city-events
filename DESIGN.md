# Обґрунтування дизайн-рішень (Варіант 5)

**Чітка вимога:** 
h1 = 32px, h2 = 22px, основний текст = 16px.
**Нечітка вимога:** 
«має передавати атмосферу свята»

**Обґрунтування:**
Для передачі настрою я обрав насичений фіолетовий колір для заголовка сторінки, який психологічно асоціюється з урочистостями, вечірніми заходами та святковим настроєм. Додатковим святковим акцентом виступає золото-жовтий колір для бейджів категорій. 
Щоб зберегти читабельність основного тексту та не перевантажувати інтерфейс, фон карток та сторінки залишено стандартними. 
Контраст білого тексту на фіолетовому фоні шапки становить понад 4.5:1, що повністю задовольняє стандарти доступності WCAG.
